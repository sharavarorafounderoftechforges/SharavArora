## Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/sharavarorafounderoftechforges/SharavArora.git
```

2. Navigate to the directory:
```bash
cd SharavArora
```

3. Open `index.html` in your browser:
```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

Or use a local development server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

Then visit `http://localhost:8000` in your browser.
